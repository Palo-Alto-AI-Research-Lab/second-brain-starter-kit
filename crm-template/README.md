# CRM-Template — markdown-CRM «одна карточка = один файл»

Минимальная CRM без баз данных и внешних сервисов (принцип АК-47: чинится
руками). Работает в любом Obsidian-волте; Claude Code ведёт её сам.

## Структура

```
04-Projects/<your-domain>/crm/
  cards/           # одна карточка на человека: card-imya-familiya.md
  _pipeline.md     # сводка «кто на каком этапе» (Claude перестраивает сам)
  _checklist.md    # чек-лист онбординга нового клиента/студента
```

## Карточка (см. card-template.md)

Обязательные поля: имя · контакт · источник · этап воронки · следующий шаг ·
дата следующего шага. Всё остальное — свободные заметки хронологией вниз.

## Правила ведения (добавь своему Claude в CLAUDE.md)

- Новый контакт → сразу карточка (не «потом»).
- Перед любым разговором с человеком → сначала подними его карточку.
- После разговора → допиши итог + следующий шаг с датой.
- У каждой карточки ВСЕГДА заполнен «следующий шаг» — карточка без следующего
  шага считается сломанной, Claude сам это подсвечивает.
- `_pipeline.md` перестраивается из карточек (Claude делает это по команде
  или в конце сессии) — правь карточки, не сводку.
- Просрочен следующий шаг → Claude показывает это первым делом («красная зона»).
