# Teaser Writing Playbook

КРАТКО: сильный «крючок» в первой строке = до **+65% вовлечённости**. Тизер = психология (любопытство/эмоция/противоречие) × конкретика/польза + клиффхэнгер со ссылкой вниз.

## На каком этапе (контент-фабрика v2, S0–S6)
- **Пишется на S5** — EPISODE_ADAPTER (адаптеры по тирам, skill `/episode`). Тир `teaser`: ClawRus(RU) · X(EN), 240–370 симв (HARD для ClawRus; X ≤280), голос = **только Opus**, кросс-ссылка вниз → longread, canonical → GitHub. Контракт §7.2 → decision-content-pipeline-reality-show [internal].
- **Публикуется на S6** (Distribute) — draft-first, наружу только по «+»/QQQ Антона (Tier-2). Кросс-пост в @ClawRus = [[reglament-tizery-krosspost-v-clawrus-i-tg]].
- **FB-первый поток (обратный вход):** если пост уже на стене FB без тизера — skill `/fb-watch` + рутина `fb-watch-daily` сами пишут тизер по этому плейбуку. Память teaser-crosspost-clawrus [internal].

## Алгоритм (6 шагов)
1. Взять ГОТОВЫЙ пост-материал (из S4 или FB-пост), не сырьё.
2. Выбрать ОДИН приём (не больше — размывается).
3. Крючок в первую строку (инфо-разрыв / дерзкое утверждение / цифра).
4. Промис + клиффхэнгер: что читатель выиграет, но не раскрыть → ссылка вниз.
5. Прогнать 4U-чек. Не прошёл → переписать.
6. Замерить длину детерминированно (240–370 / X ≤280); голос Opus; выдать 2–3 A/B-версии.

## 6 приёмов (триггеров)
- **Любопытство (тайна)** — инфо-разрыв: «Секрет X? Это не то, что вы думаете».
- **Противоречие / шок** — против консенсуса: «Контент-маркетинг МЁРТВ».
- **Конкретика / польза** — числа, шаги, результат: «Сделал X → получил Y».
- **Эмоция / FOMO** — «уже 100 инженеров участвуют».
- **Прямое обращение** — «Если ты устал от…».
- **Обещание** — чётко: что читатель получит (навык/решение).

## Правило 4U (чек каждого тизера)
**U**rgent (бьёт по боли сейчас) · **U**nique (необычный ракурс) · **U**seful (реальная польза) · **U**ltra-specific (конкретика, числа).

## Критерии качества
Hook (мгновенно цепляет) · Ясность/релевантность (не вводит в заблуждение) · Promise (видно, что выиграю) · Уникальность (не пустой крючок) · Краткость в лимит.

## A/B-тест (выбрать победителя)
2–3 версии → показ разным подгруппам → метрики (CTR, ретвиты/лайки, bounce) → победитель → перепроверка сменой групп. Итерировать.

## Шаблон промпта для модели
> Ты — опытный копирайтер. Перед тобой текст поста (RU). Напиши цепляющий твит-тизер (≤280 симв), используя ОДИН приём: любопытство / противоречие / польза / FOMO / юмор / загадка. Не раскрывай всё, оставь интригу. Тизер должен побудить перейти к полному тексту.

## Примеры (curiosity / FOMO / провокация / числа)
- «Секрет X? Это не то, что вы думаете».
- «Все сейчас пробуют этот тренд — а вы?».
- «Контент-маркетинг МЁРТВ — вот что делать вместо него».
- «Сделал одно изменение — доход утроился за 3 месяца».
