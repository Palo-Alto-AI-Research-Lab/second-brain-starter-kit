# Как контрибьютить

Это открытая стройка. Если что-то откликнулось и хочется добавить — паттерн,
починку, тест, правку в доке, идею — пул-реквесты приветствуются.

## Единственные ворота: АК-47

Каждый вклад проверяется одним принципом — **простота АК-47**:

1. **Просто** — самое маленькое решение, которое закрывает задачу.
2. **Чинится молотком** — не-инженер должен понять и починить сам.
3. **Переживает плохие условия** — работает при кривой связи, лимитах токенов,
   без модной инфраструктуры.
4. **Полезно обычному человеку**, а не только программисту. Должно снимать
   настоящую боль.

Если правка добавляет зависимость, сервис или абстракцию — в PR одной строкой:
какую боль лечит, что сломается без неё, какую более дешёвую альтернативу
рассмотрели.

## Как

1. Для всего нетривиального сперва issue — договоримся о форме до кода.
2. PR держим маленькими и по одной теме.
3. «Почему» объясняем простыми словами.
4. Никаких секретов, персональных данных и чужих имён в примерах — только
   синтетика.
